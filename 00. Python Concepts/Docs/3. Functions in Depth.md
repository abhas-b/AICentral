## Functions are objects — really objects

You know functions are first-class (assignable, passable, returnable). Go one level deeper:
a function is a full object with inspectable attributes and mutable state.

```python
def greet(name: str, punctuation: str = "!") -> str:
    "Return a greeting."
    return f"Hi {name}{punctuation}"

print(greet.__name__)         # greet
print(greet.__doc__)          # Return a greeting.
print(greet.__defaults__)     # ('!',)              default values
print(greet.__annotations__)  # {'name': <class 'str'>, 'punctuation': ..., 'return': ...}
print(greet.__code__.co_varnames)  # ('name', 'punctuation')  local names

greet.call_count = 0          # you can even attach arbitrary attributes
```

Because functions are objects, you can store them in data structures and build **dispatch
tables** — often cleaner than long `if/elif` chains:

```python
def buy(qty):  return f"bought {qty}"
def sell(qty): return f"sold {qty}"

actions = {"BUY": buy, "SELL": sell}      # a dict of functions
print(actions["BUY"](10))                 # bought 10
```

This "functions are values" mindset is the foundation for everything below.

## 1. Scope and the LEGB rule

When you reference a name, Python searches four scopes **in order**:

- **L**ocal — names assigned inside the current function.
- **E**nclosing — names in any enclosing (outer) function.
- **G**lobal — names at module (file) level.
- **B**uilt-in — names in the `builtins` module (`len`, `print`, `range`, …).

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        # no local x, so Python walks L -> E and finds 'enclosing'
        print(x)
    inner()

outer()          # enclosing
print(len)       # found in Built-in scope
```

### Assignment makes a name local — and the `UnboundLocalError` trap

Assigning to a name *anywhere* in a function makes it **local for the whole function**, even
before that assignment line. This causes a classic surprise:

```python
count = 10

def broken():
    print(count)     # UnboundLocalError!
    count = count + 1

# broken()  -> UnboundLocalError: local variable 'count' referenced before assignment
```

Because `count` is assigned inside `broken`, Python treats *every* `count` in the function
as local — so the `print` refers to a local that doesn't exist yet.

### `global` and `nonlocal` — rebinding outer names

To *reassign* a name from an outer scope, you must declare your intent:

```python
counter = 0

def bump_global():
    global counter          # rebind the module-level name
    counter += 1

bump_global(); bump_global()
print(counter)              # 2


def make_accumulator():
    total = 0
    def add(n):
        nonlocal total      # rebind the ENCLOSING function's 'total'
        total += n
        return total
    return add

acc = make_accumulator()
print(acc(10), acc(5))      # 10 15
```

- `global` → rebind a module-level variable.
- `nonlocal` → rebind a variable in the nearest enclosing function scope.
- You only need them to **reassign**; reading an outer name needs no declaration.
- Prefer `nonlocal`/closures over `global`; heavy `global` use is a design smell.

### Exercise 1a

Write `make_running_stats()` that returns a function `update(x)`; each call adds `x` and
returns the running `(count, total, mean)` so far.

```python
    total = 0
    def update(x):
        nonlocal count, total
        count += 1
        total += x
        return (count, total, total / count)
    return update

stats = make_running_stats()
print(stats(10))   # (1, 10, 10.0)
print(stats(20))   # (2, 30, 15.0)
```

## 2. Closures and the late-binding trap

A **closure** is an inner function that captures variables from its enclosing scope and
keeps them alive after the outer function returns. The captured values live in **cell
objects**, visible on `__closure__`:

```python
def multiplier(factor):
    def multiply(x):
        return x * factor      # 'factor' captured from enclosing scope
    return multiply

triple = multiplier(3)
print(triple(10))                          # 30
print(triple.__closure__[0].cell_contents) # 3   (the captured value)
```

### The trap: closures capture *variables*, not *values*

This bites everyone once. Closures capture the variable itself — so if the variable changes
later, every closure sees the new value:

```python
funcs = [lambda x: x * i for i in range(1, 4)]   # i is shared!
print([f(10) for f in funcs])    # [30, 30, 30]  😱  not [10, 20, 30]
```

All three lambdas reference the *same* `i`, which ends the loop at `3`. The fix is to bind
the current value at definition time via a default argument (defaults are evaluated once,
when the function is defined):

```python
funcs = [lambda x, i=i: x * i for i in range(1, 4)]   # capture value now
print([f(10) for f in funcs])    # [10, 20, 30]  ✅
```

**Remember this** — it reappears with lambdas in loops, event callbacks, and deferred tasks.

## 3. Decorators — cementing the bits we didn't cover

You have the core. Two refinements worth locking in.

### Signatures survive with `functools.wraps` (and `inspect` sees through)

`@functools.wraps` copies not just `__name__`/`__doc__` but also `__wrapped__`, which lets
`inspect` recover the *original* signature — important for tooling and for the milestone.

```python
import functools, inspect

def trace(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@trace
def place(symbol: str, qty: int) -> str:
    return f"{qty} {symbol}"

print(inspect.signature(place))   # (symbol: str, qty: int) -> str
print(place.__wrapped__)          # <function place ...>  (the undecorated original)
```

### Stacking order, one more time

`@a @b @c def f` means `f = a(b(c(f)))`: the decorator **nearest the `def` runs first**
(innermost), the top one wraps last (outermost). At call time, the outermost runs first.
Keep this straight when order matters (e.g. `@timed` outside `@retry` measures all retries;
inside, it measures one attempt).

> is in tutorial 1. We'll *use* all of it in the milestone.

## 4. The `functools` toolkit

The standard library's function-tools module. Know every one of these — they turn five-line
helpers into one-liners.

### `partial` — freeze some arguments

Creates a new callable with some arguments pre-filled:

```python
from functools import partial

def power(base, exp):
    return base ** exp

square = partial(power, exp=2)      # freeze exp=2
cube = partial(power, exp=3)
print(square(5), cube(2))           # 25 8

basetwo = partial(int, base=2)      # int(x, base=2), a binary parser
print(basetwo("1010"))              # 10
```

`partial` is the Pythonic way to do **partial application / currying**, and it's cleaner
than a lambda for callbacks (`button.on_click(partial(handle, user_id=42))`).

### `partialmethod` — `partial` for methods in a class body

```python
from functools import partialmethod

class Switch:
    def __init__(self):
        self.on = False
    def set(self, state):
        self.on = state
    turn_on = partialmethod(set, True)
    turn_off = partialmethod(set, False)

s = Switch(); s.turn_on()
print(s.on)   # True
```

### `reduce` — fold a sequence to a single value

```python
from functools import reduce
from operator import mul

product = reduce(mul, [1, 2, 3, 4], 1)   # ((((1*1)*2)*3)*4)
print(product)                            # 24
```

Use sparingly — a plain loop or `sum`/`math.prod` is often clearer. `reduce` shines for
genuine custom folds.

### `lru_cache` / `cache` — automatic memoization

```python
from functools import lru_cache

@lru_cache(maxsize=None)      # or @functools.cache  (3.9+), same as maxsize=None
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

print(fib(100))               # instant despite naive recursion
print(fib.cache_info())       # CacheInfo(hits=98, misses=101, ...)
fib.cache_clear()
```

Caches by argument tuple (args must be **hashable**). Don't cache functions with side
effects or unbounded, ever-changing arguments (memory leak).

### `cached_property` — compute once per instance

```python
from functools import cached_property

class Dataset:
    def __init__(self, rows):
        self.rows = rows
    @cached_property
    def mean(self):
        print("computing…")
        return sum(self.rows) / len(self.rows)

d = Dataset([1, 2, 3])
print(d.mean)    # computing… -> 2.0
print(d.mean)    # 2.0  (cached; no recompute)
```

Stores the result in the instance `__dict__` (so it's incompatible with `__slots__` unless
you add a `__dict__` slot).

### `singledispatch` — overload a function by argument type

```python
from functools import singledispatch

@singledispatch
def to_json(obj):
    raise TypeError(f"no JSON encoder for {type(obj).__name__}")

@to_json.register
def _(obj: int):
    return str(obj)

@to_json.register
def _(obj: str):
    return f'"{obj}"'

@to_json.register
def _(obj: list):
    return "[" + ", ".join(to_json(x) for x in obj) + "]"

print(to_json([1, "a", 2]))   # [1, "a", 2]
```

Cleaner than `isinstance` ladders, and extensible — register new types from anywhere.
`singledispatchmethod` does the same for methods (dispatches on the first non-`self` arg).

### `total_ordering` and `cmp_to_key`

`total_ordering` (seen in tutorial 1) fills in all comparisons from `__eq__` + `__lt__`.
`cmp_to_key` adapts an old-style two-argument comparison function into a `key=` function:

```python
from functools import cmp_to_key

def by_length_then_alpha(a, b):
    if len(a) != len(b):
        return len(a) - len(b)      # negative: a first; positive: b first
    return (a > b) - (a < b)        # tie-break alphabetically

words = ["banana", "kiwi", "fig", "apple"]
print(sorted(words, key=cmp_to_key(by_length_then_alpha)))
# ['fig', 'kiwi', 'apple', 'banana']
```

Prefer a plain `key=` when you can; reach for `cmp_to_key` only when comparison is
inherently pairwise.

### Exercise 4

Using `singledispatch`, write `size(obj)` returning: for `int`, the number itself; for
`str`, its length; for `list`/`tuple`, the sum of `size` of its elements; and raise for
anything else.

<details><summary>Solution</summary>

```python
from functools import singledispatch

def size(obj):
    raise TypeError(f"unsupported: {type(obj).__name__}")

@size.register
def _(obj: int):
    return obj

@size.register
def _(obj: str):
    return len(obj)

@size.register(list)
@size.register(tuple)
def _(obj):
    return sum(size(x) for x in obj)

print(size([1, "ab", (3, "c")]))   # 1 + 2 + (3 + 1) = 7
```

## 5. Functional-style programming

Python supports a functional style but isn't dogmatic about it. Know the tools; choose
readability.

### `map` / `filter` vs comprehensions

```python
nums = [1, 2, 3, 4, 5]

# map/filter (lazy iterators)
doubled = map(lambda x: x * 2, nums)
evens = filter(lambda x: x % 2 == 0, nums)

# comprehensions — usually clearer for inline logic
doubled = [x * 2 for x in nums]
evens = [x for x in nums if x % 2 == 0]
```

**Guidance:** comprehensions win when the transform is a small inline expression.
`map`/`filter` win when you already have a *named* function (`map(str.upper, words)`) and
when you want laziness over a huge stream. Don't write `map(lambda …)` — that's a
comprehension in disguise, less readable.

### `sorted` / `min` / `max` with `key`

```python
trades = [
    {"symbol": "INFY", "pnl": 1200},
    {"symbol": "TCS",  "pnl": -300},
    {"symbol": "REL",  "pnl": 800},
]
print(max(trades, key=lambda t: t["pnl"]))      # the INFY dict
print(sorted(trades, key=lambda t: t["pnl"]))   # ascending by pnl
```

### The `operator` module — faster, clearer `key` functions

`operator` provides ready-made accessors that replace tiny lambdas and run a bit faster:

```python
from operator import itemgetter, attrgetter, methodcaller

# itemgetter: index/key access
print(sorted(trades, key=itemgetter("pnl")))            # by one key
print(sorted(trades, key=itemgetter("pnl", "symbol")))  # multi-key sort!

# attrgetter: attribute access on objects
class P:
    def __init__(self, name, age): self.name, self.age = name, age
people = [P("a", 30), P("b", 25)]
print([p.name for p in sorted(people, key=attrgetter("age"))])   # ['b', 'a']

# methodcaller: call a method on each element
words = ["  Hi ", " There "]
print(list(map(methodcaller("strip"), words)))          # ['Hi', 'There']
```

`itemgetter` with multiple keys is the idiomatic multi-field sort — no lambda needed.

### Composition and currying

Python has no built-in `compose`, but it's a three-liner, and `partial` gives you currying:

```python
def compose(*funcs):
    def composed(x):
        for f in reversed(funcs):   # apply right-to-left, like math
            x = f(x)
        return x
    return composed

clean = compose(str.strip, str.lower)   # strip THEN lower
print(clean("  HELLO "))                # hello
```

### When *not* to go functional

Deeply nested `map`/`filter`/`reduce`/`lambda` chains are hard to read and debug (no
intermediate names, unclear tracebacks). Python's culture favors comprehensions and clear
loops. Use functional tools where they *increase* clarity, not to prove a point.

### Exercise 5

Given a list of `(name, score)` tuples, use `operator` and `sorted` to produce names sorted
by score descending, then name ascending, with **no lambdas**.

<details><summary>Solution</summary>

```python
from operator import itemgetter

data = [("bob", 90), ("amy", 90), ("cy", 85)]
# sort by name ascending first, then by score descending (stable sort trick),
# OR use a single key with a sign flip:
ranked = sorted(data, key=lambda x: (-x[1], x[0]))   # (lambda allowed for the flip)
# no-lambda version: sort in two stable passes
by_name = sorted(data, key=itemgetter(0))            # ascending name
ranked = sorted(by_name, key=itemgetter(1), reverse=True)  # then score desc
print([name for name, _ in ranked])   # ['amy', 'bob', 'cy']
```

*(The two-pass stable-sort technique is the clean no-lambda way to do "descending by X,
ascending by Y": sort by the secondary key first, then by the primary key.)*
</details>

## 6. Callable introspection with `inspect`

To build decorators that validate or adapt arguments, you must read a function's signature
at runtime. `inspect` is the tool.

```python
import inspect

def order(symbol: str, qty: int = 1, *legs, price: float, **meta) -> str:
    ...

sig = inspect.signature(order)
print(sig)                         # (symbol: str, qty: int = 1, *legs, price: float, **meta) -> str

for name, p in sig.parameters.items():
    print(f"{name:8} kind={p.kind.name:20} default={p.default!r} ann={p.annotation}")
# symbol   kind=POSITIONAL_OR_KEYWORD default=<empty> ann=<class 'str'>
# qty      kind=POSITIONAL_OR_KEYWORD default=1       ann=<class 'int'>
# legs     kind=VAR_POSITIONAL        default=<empty> ...
# price    kind=KEYWORD_ONLY          default=<empty> ...
# meta     kind=VAR_KEYWORD           default=<empty> ...
```

The five **parameter kinds**: `POSITIONAL_ONLY` (before `/`), `POSITIONAL_OR_KEYWORD` (the
normal case), `VAR_POSITIONAL` (`*args`), `KEYWORD_ONLY` (after `*`), `VAR_KEYWORD`
(`**kwargs`).

### Binding arguments to parameters

`sig.bind(*args, **kwargs)` maps a *call* onto the parameters — exactly what a validating
decorator needs to know "which value went to which parameter":

```python
def f(a, b=2, c=3):
    ...

bound = inspect.signature(f).bind(1, c=99)
bound.apply_defaults()             # fill in b's default
print(bound.arguments)             # {'a': 1, 'b': 2, 'c': 99}
```

This `bind` + `apply_defaults` pattern is the backbone of the `@validate_types` decorator in
the milestone.

### Exercise 6

Write `describe(func)` that prints each parameter's name, whether it's required (no
default), and its annotation (or "any"). Use `inspect`.

<details><summary>Solution</summary>

```python
import inspect

def describe(func):
    for name, p in inspect.signature(func).parameters.items():
        required = p.default is inspect.Parameter.empty
        ann = p.annotation if p.annotation is not inspect.Parameter.empty else "any"
        ann_name = getattr(ann, "__name__", ann)
        print(f"{name}: {'required' if required else 'optional'}, type={ann_name}")

def sample(x: int, y: str = "hi", *args): ...
describe(sample)
# x: required, type=int
# y: optional, type=str
# args: required, type=any
```
</details>

## Milestone Project — a reusable decorator library

Build `deckit` — a small module of production-quality, **signature-preserving,
stackable** decorators. This cements decorators and exercises `functools` + `inspect`.

Requirements:

1. `@timed` — logs wall-clock time; correct even if the function raises.
2. `@retry(attempts=3, exceptions=(Exception,), delay=0, backoff=1.0)` — re-runs on failure
   with optional exponential backoff; re-raises the last exception.
3. `@memoize` — caches results by arguments (understand the mechanism; note where
   `lru_cache` is the real tool).
4. `@log_calls` — logs the call with arguments and the return value.
5. `@validate_types` — enforces the function's type annotations, using
   `inspect.signature`.
6. All must preserve the wrapped function's signature (so `inspect.signature` still works)
   and be freely stackable.

Try it before opening the solution.

<details><summary>Reference solution</summary>

```python
"""deckit — a tiny reusable decorator library."""
import functools
import inspect
import time


def timed(func):
    """Log how long the call took (even on exception)."""
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            ms = (time.perf_counter() - start) * 1000
            print(f"[timed] {func.__name__} took {ms:.2f} ms")
    return wrapper


def retry(attempts=3, exceptions=(Exception,), delay=0.0, backoff=1.0):
    """Retry on failure with optional exponential backoff."""
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            wait, last = delay, None
            for i in range(1, attempts + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions as exc:
                    last = exc
                    print(f"[retry] {func.__name__} attempt {i}/{attempts} failed: {exc}")
                    if i < attempts and wait:
                        time.sleep(wait)
                        wait *= backoff
            raise last
        return wrapper
    return decorator


def memoize(func):
    """Cache results by positional args (hashable only).

    NOTE: for real code use functools.lru_cache / functools.cache — this hand-rolled
    version exists to show the mechanism (a dict keyed by the argument tuple).
    """
    cache = {}
    @functools.wraps(func)
    def wrapper(*args):
        if args not in cache:
            cache[args] = func(*args)
        return cache[args]
    wrapper.cache = cache               # expose for inspection/clearing
    return wrapper


def log_calls(func):
    """Log the call signature and the result."""
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        rendered = ", ".join(
            [repr(a) for a in args]
            + [f"{k}={v!r}" for k, v in kwargs.items()]
        )
        print(f"[call] {func.__name__}({rendered})")
        result = func(*args, **kwargs)
        print(f"[call] {func.__name__} -> {result!r}")
        return result
    return wrapper


def validate_types(func):
    """Enforce simple type annotations at call time via inspect."""
    sig = inspect.signature(func)
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        bound = sig.bind(*args, **kwargs)
        bound.apply_defaults()
        for name, value in bound.arguments.items():
            expected = sig.parameters[name].annotation
            # only check concrete, isinstance-able type annotations
            if isinstance(expected, type) and not isinstance(value, expected):
                raise TypeError(
                    f"{func.__name__}: argument {name!r} must be "
                    f"{expected.__name__}, got {type(value).__name__}"
                )
        return func(*args, **kwargs)
    return wrapper


# ------------------------- exercise the library -------------------------
if __name__ == "__main__":
    @timed
    @log_calls
    @validate_types
    def compute(x: int, y: int) -> int:
        return x * y + 1

    print(compute(3, 4))
    # [call] compute(3, 4)
    # [call] compute -> 13
    # [timed] compute took 0.xx ms
    # 13

    # signature is preserved through all three decorators:
    print(inspect.signature(compute))     # (x: int, y: int) -> int

    # validation fires:
    try:
        compute(3, "four")
    except TypeError as e:
        print("caught:", e)               # caught: compute: argument 'y' must be int, got str

    # memoize + retry combo
    attempts = {"n": 0}

    @retry(attempts=3, exceptions=(ValueError,), delay=0.01, backoff=2.0)
    def flaky():
        attempts["n"] += 1
        if attempts["n"] < 3:
            raise ValueError("transient")
        return "ok"

    print(flaky())                        # retries twice, then "ok"

    @memoize
    def slow_add(a, b):
        time.sleep(0.05)
        return a + b

    print(slow_add(2, 3))                 # slow first time
    print(slow_add(2, 3))                 # instant (cached)
    print(slow_add.cache)                 # {(2, 3): 5}
```

**Why it's well-built:**

| Feature | Technique |
|---|---|
| Timing survives exceptions | `try/finally` in the wrapper |
| Retry with backoff | 3-layer decorator (args → decorator → wrapper) + closure state |
| Memoize | closure-held `dict` keyed by args (or `lru_cache` in production) |
| Type validation | `inspect.signature` + `bind` + `apply_defaults` |
| Signatures preserved | `functools.wraps` on every wrapper |
| Stackable | each decorator returns a plain wrapped callable |

**Stretch goals:** give `memoize` a `maxsize` (or delegate to `lru_cache`); add
`@deprecated(reason)` using `warnings.warn`; add `@rate_limit(calls, per_seconds)`; make
`validate_types` also check the return annotation.

</details>
